# Calculator visual asset

`ti84-plus-ce.jpg` is a downloaded TI-84 Plus CE reference photograph used by
the local emulator preview skin. The source is the Wikimedia Commons image
linked from the TI-84 Plus CE series article:

<https://upload.wikimedia.org/wikipedia/commons/d/d0/TI-84_Plus_CE_%28red%29.jpg>

The emulator screen is rendered by CEmu; this photograph is only the visual
calculator body around that screen.
